# 运行与排障

接收路径：iPhone → BLE / ANCS → 独立 AncsReader.exe → C# 后台 → 剪贴板。

所有命令都通过 `dist/SmsCodeClipper.exe` 调用：

- `--open` 打开面板，必要时启动后台；`--background` 重启后台；`--stop` 停止。
- `--status --json` 查看连接状态、错误、接收器 PID 和距上次心跳的秒数。
- `--latest --json` 查询最近验证码；`--wait 120 --json` 等待新验证码；`--dump --limit 20 --json` 查询本地通知缓存。
- `--ensure --owner-pid PID --json` 按需启动，并在新建后台时跟随所属进程退出。
- `--shortcut` 创建桌面快捷方式；`--autostart on|off` 设置登录自启；`--chime` 试听提示音。
- `--help` 查看参数；`--data-dir PATH` 指定数据目录。

## 接收失败

1. 首次使用需在 Windows 中配对 iPhone，并在手机蓝牙设备详情中开启“共享系统通知”。面板里选择手机并连接。
2. `disconnected` 表示主动断开或尚未选择手机；`reconnecting` 时检查蓝牙、手机距离和通知授权，再看 `source_error`。
3. 已连接但没收到验证码时，检查手机是否产生通知、是否被清除，以及两端时间是否一致。重连仅补收后台运行期间最近两分钟的通知，初次启动只接受启动前五秒以内及之后的通知，无法获取完整短信历史。
4. 有验证码但未复制时检查暂停状态和剪贴板占用；复制失败会保留记录，可点击面板手动复制。自动填入还受应用白名单、窗口焦点和管理员权限限制。

窗口查询设备或验证连接时最多等待 30 秒，后台设备枚举时限为 20 秒。看到“设置未保存”时，检查数据目录是否可写以及磁盘空间是否充足，再重试。

窗口关闭后后台继续运行，可从托盘打开或退出。Insert 热键输入设置的手机号；自动填入不自动按回车。

## 更新与验证

更新前先关闭面板并运行 `--stop`，再执行 `./scripts/build.ps1 build` 和 `./scripts/build.ps1 test`。运行版本仅需 Windows，发布目录自带 .NET 运行时。

移动发布目录后，可运行 `--shortcut` 或 `--autostart on` 更新系统入口。

实机验证：锁屏接收一条新验证码，核对面板、剪贴板以及 `code_seq`；再检查断线重连。不要上传真实短信、手机号或验证码日志。
